# 🤖 کاوان بات — نسخه هوشمند (Node.js + LLM)

بات تلگرامی ۲۴/۷ گروه «Taj Parsian Gp» با مغز هوش مصنوعی (z-ai-web-dev-sdk / GLM).

## قابلیت‌ها
- جواب هوشمند به منشن و ریپلی (با شخصیت کاوان)
- جواب‌های خودکار تصادفی به گفتگوی عادی گروه (قابل تنظیم با `CHATTER_PROBABILITY`)
- دستورهای ارباب: «تگ @فلانی» و «پنل»
- پنل مدیریت با دکمه‌های زنده (بروزرسانی / ادمین‌ها / وضعیت)
- آرشیو همه رویدادها در `kavan_archive.jsonl`
- اگر LLM در دسترس نباشه، خودکار به حالت قالبی برمی‌گرده

## متغیرهای محیطی
| متغیر | توضیح |
|---|---|
| `BOT_TOKEN` | توکن ربات تلگرام (الزامی) |
| `OWNER_ID` | آیدی عددی ارباب |
| `ZAI_CONFIG_JSON` | محتوای `.z-ai-config` (اختیاری — فعال‌کننده مغز هوش مصنوعی) |
| `CHATTER_PROBABILITY` | شانس جواب خودکار ۰ تا ۱ (پیش‌فرض 0.35) |
| `COOLDOWN_SECONDS` | حداقل فاصله بین جواب‌های خودکار (پیش‌فرض 45) |

## اجرا

```
npm install
node server.js
```
